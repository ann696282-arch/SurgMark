# SurgMark ESD · 术标

胃 ESD 视频与图片标注工具 v3.0.0，依据医生提供的分期分级规则及两例视频试标说明调整。

## 下载安装

在 [Releases](https://github.com/ann696282-arch/SurgMark/releases) 下载对应的 **Windows.zip** 或 **macOS.zip**，完整解压。人工标注无需 Python、无需联网。

- **Windows**：双击 `install-windows.cmd`，安装到当前用户的本地应用目录，并建立桌面快捷方式。若系统脚本策略不允许运行，可直接用 Chrome / Edge 打开 `SurgMark-ESD/index.html`。
- **Mac**：双击 `install-macos.command`，安装到 `~/Applications/SurgMark-ESD`。也可直接用 Chrome / Edge 打开 `SurgMark-ESD/index.html`，无需执行脚本。

这是本地浏览器应用的安装／便携包，不是 EXE、DMG 或签名原生应用。双击打开时仅运行本机 HTML/JavaScript，不上传视频。请保留整个应用文件夹，不要只复制 index.html。校验文件见 SHA256SUMS.txt。

## 三层标注

**表A：主要操作时间轴** — 准备、标记、注射、环切、剥离、止血；记录明确／存疑及备注。按实际操作记录，允许环切与剥离交替；其他阶段回切提示核对。已确认的主要操作不允许互相重叠。

**表B：状态区间** — 分别评价注射后抬举、切口完整性、剥离层面、出血及创面状态，填写评价区域、可见依据、证据时刻或区间及无法评级原因。

| 对象 | 可用分级 |
|---|---|
| 注射后黏膜下抬举 | 0、1、NA |
| 黏膜切开完整性 | 0、1、2、NA |
| 剥离层面状态 | 0、1、2、NA |
| 出血及创面状态 | 0、1、2、NA |

分级描述按医生补充规则内置。**NA 与0级不同**，NA 必须填写原因。医生提供的“标记下1/3为安全区域”按原意显示；工具不自动识别或推断安全区，也不把单帧评分赋予整段视频。

**表C：少量操作质量事件** — 记录事件编号、评价条目、三级或符合／不符合判定、医生商定的适用情境与分档描述、行为证据及病例困难；均保留 NA，不合成总分。局部状态不直接等同于操作质量。

三层时间区间允许相互重叠。0级可能出现在操作正式开始前，因此状态未被同类操作包含时仅提示核对，不硬性禁止。

## 数据模式

- 完整视频：默认包含六类分期及 NA / Other。
- file1：允许 NA / Other 分期。
- file2：作为医生描述的“相对分期明确图片”模式，分期列表不显示 NA / Other；证据不足的状态仍可使用 NA，防止强制评分。

file1 / file2 是医生现有数据集说明，不自动推断用户文件的类别。Other 的定义为视野不清或图像质量差。器械更换、观察、冲洗等尚未确定归类的情况，记录存疑和备注供讨论。

## 医生操作流程

1. 保存匿名病例编号、匿名术者编号、规则版本。
2. 添加一例病例的原始视频／图片，可多文件；为每个素材设置独立编号。原始完整文件的时间偏移为0；拆分文件填写其在原始手术中的起始时间。
3. 填写标注者编号并保存会话署名。I 设置起点、O 设置终点，Enter 保存。图片的起止使用同一原视频证据时刻。
4. 先标表A，再按有意义的状态变化标表B；只挑少量代表事件试标表C。
5. 另一位医生在“标注／复核人”栏输入新编号后，点击“新建独立会话”。原结果仍保留，但当前表格只显示新会话。
6. 讨论时在署名栏输入讨论小组编号，点击“从当前会话建立共识”。源会话被复制为待审核共识初稿；独立结果保留，可切换会话对照。异机结果用“合并独立结果”导入，同编号内容冲突时拒绝覆盖。
7. 定期保存项目 JSON。分别导出表A、B、C；所有会话均导出并带审核状态，后续使用时筛选 accepted。
8. 规则变更时修改规则版本并填写修订说明；已标结果保留旧版本，需人工复评。修改历史、会话计时可独立导出。

项目按病例保存。视频／图片只保留文件名、大小和对应关系，不包含原始素材；JSON 恢复后重新选择原文件。不要依赖浏览器缓存作为唯一备份。计时只统计页面可见且最近5分钟内有操作时的工具内耗时。

## 可选 AI

人工流程不需要 AI。CLIP 仅抽帧提出六类操作候选，没有经过胃 ESD 数据验证；相似度不代表准确率。每段候选均为待审核，不自动评状态或质量。医生需检查类别与边界。SlimSAM 仅为当前帧点击分割，不是视频追踪，常规试标无需画掩码。

需要 AI 时，推荐 Python 3.11，在应用目录创建虚拟环境后安装和启动：

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python download_models.py
python server.py
```

打开 http://127.0.0.1:8765 。首次下载模型需要联网，权重不在安装包中；后续推理读取本地权重。默认自动选择 CUDA / MPS / CPU，性能需按实际硬件测试。

## 版本兼容与验证

旧版通用动作标签不能自动转成胃 ESD 医学标签；旧项目请通过 `legacy-v1.html` 查看和导出。v3 项目使用独立缓存，不覆盖旧版缓存。

包含13项规则／数据测试与本机接口测试，并用合成素材检查浏览器标注、导出、保存恢复。没有真实病例准确率验证。Windows 安装脚本未在真实 Windows 电脑执行验证；浏览器运行依赖其支持的视频编码，建议 MP4 H.264。逐帧步进按填写的 FPS 计算，不保证可变帧率视频逐编码帧定位。

开发测试与打包：

```sh
node core.test.js
python -m unittest discover -s . -p test_server.py
python build_packages.py
```

第三方模型：[CLIP](https://huggingface.co/openai/clip-vit-base-patch32)、[SlimSAM](https://huggingface.co/Zigeng/SlimSAM-uniform-50)，使用遵循其发布条款。仓库不上传医生原始文件、患者视频或个人标注数据。
