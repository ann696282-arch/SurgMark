SurgMark ESD 术标 v3.0.0
请阅读 README.md 获取安装、标注和导出完整说明。

Windows：完整解压后双击 install-windows.cmd；或直接打开 SurgMark-ESD/index.html。
Mac：完整解压后双击 install-macos.command；或直接打开 SurgMark-ESD/index.html。
请使用 Chrome 或 Edge，保留所有应用文件。人工标注无需 Python 或网络。

病例 → 素材对应关系 → 会话署名 → 表A主要操作 → 表B状态 → 少量表C质量事件 → 保存项目。
NA与0级不同，无法评级需写原因。注射只有0/1/NA，其余三种状态为0/1/2/NA。
输入新医生编号后点击新建独立会话；共识复制源结果为待审核，不覆盖独立结果。
JSON 不含视频，请保存原视频并定期下载 JSON。导出的 CSV 含全部会话，须按审核状态筛选。

模型权重不随包分发。AI为可选研究辅助，需要另装 Python 依赖及模型；尚未验证胃ESD识别准确率。
Windows安装脚本尚未在真实Windows电脑执行；可使用免安装浏览器入口。
